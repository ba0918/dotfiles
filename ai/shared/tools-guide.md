# LLM 向けツールガイド

コード作業で使える汎用 CLI（導入済み）。`find` / `grep` / 正規表現では構造や対象を
捉えきれないときに使う。詳細な使い方は各ツールの `--help` を参照。

- **ast-grep** (`sg`) — 構文パターンで検索・書き換え。文字列や正規表現ではなく
  AST 構造でマッチするため、特定の構文（例: `if $A { $B }`）をまとめて探したり
  置換したりできる。書き換えは `sg -p 'パターン' -r '置換'`。言語は自動検出するが、
  誤る場合は `--lang rust` 等で指定する
- **fd** — ファイル探索（`find` の代替）。gitignore を尊重し高速。
  例: `fd '\.rs$' src`
- **rg**（ripgrep）— テキスト検索（`grep` の代替）。gitignore を尊重し高速。
  例: `rg -n 'TODO' .`
- **jq** — JSON の抽出・変形。例: `jq '.dependencies' package.json`
